# 前端主题

默认使用原版。业务页面、数据和事件由 `web/app.js` 管理；主题入口位于 `web/assets/themes/`，不修改业务状态或重建页面。

- 本机切换：管理员进入「设置 → 界面主题」，点击主题按钮，无需刷新。
- 临时预览：地址加上 `?theme=studio`；返回原版用 `?theme=original`。保留原来的页面片段，例如 `/?theme=studio#knowledge`。
- 发布默认主题：修改 `config.js` 的 `defaultTheme`，重新导出并发布。已保存的浏览器个人选择优先于发布默认值，地址参数优先级最高。
- 程序调用：`await DecorThemes.set("studio")`，或 `await DecorThemes.set("original")`。回退会卸载可选样式表，不覆盖原版 CSS。

主题样式以 `html[data-theme="主题名"]` 为作用域，包含自己的变量、字体和资源。导航图标由主题 CSS 替换显示，不修改原版 HTML。主题只能调整展示；链接、表单、ID、数据属性和业务事件保持共用。结构明显不同的页面需要共享组件提供布局接口，不能让主题脚本改写业务 DOM。

新增主题时建立独立目录，并在 `config.js` 的 `themes` 中登记。原版没有附加样式；可选主题只在启用时加载。加载失败保留当前界面，连续切换以最后一次选择为准。设置写入当前浏览器，不写数据库；公开静态版仍不提供管理设置入口，可通过预览参数试用。

切换前后需检查：筛选及分页状态、已展开内容、弹窗、阅读位置、窄屏布局，以及样式加载失败后的回退。
