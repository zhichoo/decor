# 装修指南

知识库侧栏的「装修指南」是一份只读专题，目前只有一篇：`content/guides/all-inclusive-company.json`（选装修公司指南）。

## 内容从哪来

正文仍在 `md/guide-draft-*.md` 里编辑，改完后转换成 JSON：

```bash
.venv/bin/python scripts/import_guide_markdown.py --updated-at 2026-11-18
```

- 只读地连接本地数据库，把注释里的 `` `claim_xxxxxxxx` ``（卡片 ID 前 8 位）换成完整 ID，并记下卡片的内容指纹。
- 结构有问题（缺注释、清单指向不存在的小节、ID 重复等）时直接报错，不写文件。
- 草稿约定：每节用“要点／避坑／要问／要材料／不同说法”区块；注释写在文末 `## 注释`；附录清单写在 `md/guide-draft-appendix-*.md`，条目后用 `` `5.4` `` 标出处小节，用 `` `半包` `` 等标适用范围。
- 附录的“要拿到的材料”表固定为四列：时间｜材料｜里面要写明｜出处。“里面要写明”用全角分号“；”分隔，页面上每一项都是一个可勾选的核对点；出处里的小节编号必须存在。表格前后的段落分别作为说明和依据显示。

## 卡片变化时怎么办

```bash
.venv/bin/python scripts/check_guides.py
```

只读检查。退出码 0 表示一切正常；1 表示结构错误，不能发布；2 表示有卡片被删或内容变了，页面仍可发布，但受影响的内容会降级：

- 卡片已删除，或者结论、条件、引句、立场等字段变了：这张卡不再显示，注释里改成“资料待补充”。
- 某条正文只靠知识卡支撑（注释以“知识库：”开头），而且这些卡全部失效：这条正文也改成“资料待补充”。
- 注释同时引用了法规、报道等其他来源：正文保留，只隐藏失效的卡片，并提示“部分知识卡已变化”。

核对过新内容后，重新运行导入脚本就会写入新的指纹。

## 页面和接口

- 私有应用：`GET /api/guides`（列表）、`GET /api/guides/<slug>`（解析后的指南）。只读；公开只读实例也开放这两个接口。
- 公开静态版：`scripts/export_public.py` 会把解析后的指南写进快照的 `guides` 字段，使用和知识库相同的公开卡片集合。旧快照没有这个字段时，侧栏不显示入口。
- 前端：`web/guides.js`、`web/guides.css`。点卡片打开原卡；从原卡“查看来源”进入视频详情后返回，会回到原来的阅读位置，已展开的注释也保持展开。
- 宽度 >1280px 时目录在正文右侧（左边是应用侧栏），默认全部展开，标出正在读的章和小节；“收起”只保留章标题。宽度 ≤1280px 时目录收进左侧抽屉，左下角浮动按钮显示当前小节，点开后选小节、点遮罩或按 Esc 关闭。
- 核对清单的勾选只存在浏览器 `localStorage`（`decorGuideChecklist:<slug>`），不写后端；浏览器禁止存储时仍可临时勾选。
