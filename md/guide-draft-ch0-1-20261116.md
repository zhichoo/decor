## 0 先选模式

### 0.1 四种模式各包什么

| 俗称 | 合同写法 | 你自己买 |
| --- | --- | --- |
| 清包 | 只包工 | 全部材料 |
| 半包 | 包工＋部分材料 | 以材料表为准，通常是主材 |
| 全包 | 包工＋全部材料 | 以清单为准 |
| 整装 | 无统一写法 | 全包之外再加定制、家电、软装，差别很大 |

[^1]

**避坑**

- “全包”“包工包料”只是行业里的说法，包什么只看合同附件的清单。[^2]

**要问**

- 合同里勾选的是哪种承包方式？
- 总价含不含水电改造？
- 按面积报价时，用的是建筑面积还是套内面积？

### 0.2 按自己的情况选

| | 偏全包、整装 | 偏半包、清包 |
| --- | --- | --- |
| 能去现场的时间 | 少 | 多 |
| 看得懂材料和报价 | 不太懂 | 有经验 |
| 入住时间 | 紧 | 不急 |

全包、整装省心，但包哪些全看合同怎么写；半包、清包要自己盯材料什么时候到、和施工接不接得上。[^3]

**避坑**

- 只靠口头或微信约定、没有书面合同的，出了纠纷很难举证。[^4]

### 0.3 混合方式

很多人把基础工程交给公司，主材或定制自己买。这样做的话，每一项都要写清**谁供应、谁安装、谁保修**。业主自己买的主材，施工方通常只管安装，不管材料质保。[^5]

**要材料**：一张写明“供应方／安装方／保修方”的分工清单。

## 1 定范围

### 1.1 主材辅材分工

“包料”包哪些料，没有统一说法，同一样东西有的公司算在施工报价里，有的要你另买。全包要看套餐里含不含，半包要看哪些得自己买，签约前都拿下面这张表对一遍。[^6]

**要点**：中间一列最容易漏，逐样问清归哪边，写进材料清单。

| 阶段 | 一般含在施工报价里（辅材） | 要问清归哪边 | 一般另买或另计（主材） |
| --- | --- | --- | --- |
| 拆改、砌墙 | 砖、水泥砂浆、铁丝网 | 拆除后的垃圾外运（见 1.3） | — |
| 水电 | 给水管和管件、电线、电线管 | 暗盒、强电箱；水电是按项“预收”还是按米数和点位列明[^7] | 开关插座面板、灯具[^8] |
| 防水、瓦工 | 水泥砂浆、防水涂料 | 瓷砖胶、勾缝剂和美缝[^9]；下水管隔音棉[^10] | 瓷砖、过门石和窗台石、地漏[^8] |
| 木工 | 石膏板、龙骨、基层板 | 吊顶：石膏板吊顶通常算施工，集成吊顶和铝扣板通常算主材[^8] | 门和门套、定制柜 |
| 油漆 | 腻子、界面剂、嵌缝带 | 乳胶漆的品牌、遍数和颜色数[^11] | 壁纸、墙板 |
| 安装 | 玻璃胶 | 角阀、软管[^12] | 洁具、橱柜和台面、暖气片、窗帘杆 |

[^13]

半包最常出问题的地方，是自己买的材料和施工接不上。

**避坑**

- “自购材料出问题由谁负责”要拆成两问：**装坏了**算谁的，**材料本身坏了**算谁的。[^14]
- 施工方已经提出材料不合适，你仍书面同意使用的，后果可能由你承担。[^15]
- 你买的材料晚到导致停工，一般算业主的原因。[^16]
- 材料到场当场开箱检查，铺贴后才发现问题就说不清了。[^17]

**要问**

- 施工方会给材料供需时间表吗？每样材料最晚哪天到场？
- 到场由谁验收，是否留交接记录？
- 装坏了谁负责？材料本身有问题谁负责？
- 材料晚到导致停工，工期怎么算？

**要材料**：双方各一张材料明细表（品牌、型号、规格、数量），材料供需时间表，每批材料的交接记录。

### 1.2 套餐包什么、不包什么　`全包`

套餐价只覆盖它那张清单，清单以外的都可能另外收钱。

**避坑**

- 报价单的类目名称会误导：写着“水电”，可能只含小家电安装，不含全屋水电改造。[^18]
- 常见的“不包含”：全屋定制（只含橱柜）、超出数量的水电点位、复杂吊顶造型、海棠角。[^19]
- 合同约定的品牌可能被换掉，要写到型号。[^20]
- 没有变更时结算能不能超过预算，各地合同写法不同，要问清楚。[^21]
- 旧房的“一价全包”可能不含拆旧，开工后才提出来。[^22]

**要问**

- 每个类目下面具体包括哪些项目？
- 点位、面积这类有数量的项目，超出部分怎么计价？
- 全屋定制、家电是否包含？具体是哪几件？
- 赠送项目有没有单独的清单？
- 损耗、运输、税费是单独列，还是已经算进单价？
- 没有变更时，结算最多能超过预算多少？

**要材料**：附工艺和用料说明的预算单，写到型号的材料清单，赠送项目清单。

### 1.3 拆除、清运和其他费用

**避坑**

- 施工方只负责把垃圾清到物业指定点，运出小区的费用通常要另外约定。[^23]
- 报价里没写搬运费、水平运输费、管理费，不等于这些费用不收。[^24]

**要问**

- 拆除、外运、搬运、管理费各是多少，还是已经包含在总价里？
- 成品保护由谁做，保护哪些部位？
- 物业押金和管理费由谁出？

### 1.4 设计费

“免费设计”可能只做到平面方案，后面的设计费也可能已经算进报价或管理费。所以要问清设计费**算在哪里**。[^25]

**避坑**

- 签合同前交的意向金、设计费最容易起纠纷，交钱时写明这笔钱对应什么、能不能退。[^26]

**要问**

- 交付哪些图纸（平面、顶面、立面、水电），什么时候交？
- 图纸是否逐页签字？之后改设计怎么收费？

### 1.5 旧房和住着装修

**避坑**

- 承重结构、防水层、燃气暖气管道、外立面，有的禁止改，有的要先审批。[^27]
- 设计里有拆改承重墙，你又签字同意了，出了事你和公司都要担责。[^28]
- 二手房开工前先查前业主有没有拆改过。[^29]
- 拆改暖气、防水层出了问题，可能连累楼下；你先对邻居负责，再向公司追偿。[^30]

**要问**

- 方案是否涉及结构、防水、燃气、暖气？审批由谁去办？
- 小区允许施工的时间是什么？
- 拆旧后发现基层要修补，怎么计价？
- 住在里面施工的话，怎么隔离？物品由谁保护？

**要材料**：物业装修管理服务协议，涉及结构或管道改动时的审批文件，原始结构图。

## 签约前核对清单（第 0、1 章）

- [ ] 承包方式已写进合同
- [ ] 有“供应方／安装方／保修方”分工清单
- [ ] 对照 1.1 节的材料表，“要问清归哪边”一列逐样问过、写进了材料清单
- [ ] 双方材料表写到型号
- [ ] 有材料供需时间表（半包）
- [ ] 自购材料“装坏了”和“材料坏了”的责任已分开写明（半包）
- [ ] 每个报价类目的具体内容都看过
- [ ] 超出数量的计价方式已写明
- [ ] 定制、家电是否包含已写明
- [ ] 结算能否超预算已问清
- [ ] 拆除、外运、搬运、管理费已列明
- [ ] 签约前交的钱写明了用途和退款条件
- [ ] 图纸清单和交付时间已写明
- [ ] 结构、管道改动的审批已明确由谁办
- [ ] 现场改动必须书面确认
