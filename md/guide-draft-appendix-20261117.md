## 一、签约前

### 选模式、定范围

- [ ] 承包方式（全包、半包等）已写进合同 `0.1`
- [ ] 有一张“供应方／安装方／保修方”分工清单，设计、主辅材、定制、家电、家具都列进去了 `0.3` `1.1` `1.2`
- [ ] 对照材料表，开关面板、瓷砖胶、角阀这类“两边都有”的材料，逐样问过归哪边并写进清单 `1.1` `1.2`
- [ ] 自购材料：供料时间、进场验收、“装坏了”和“材料坏了”的责任，都已写明 `半包` `1.1` `5.5` `7.2`
- [ ] 有材料供需时间表 `半包` `1.1`
- [ ] 套餐每个类目包含的具体内容都看过，超出数量怎么计价已写明 `全包` `1.2`
- [ ] 拆除、清运、搬运、成品保护、管理费已列明 `1.3`
- [ ] 图纸清单和交付时间已写明 `1.4`
- [ ] 旧房：结构、管道改动的审批由谁办已明确；已拿到原始结构图和物业装修协议 `1.5`

### 核公司

- [ ] 签约主体、营业执照、公章、收款账户四者一致 `2.1` `5.8`
- [ ] 查过签约公司的成立时间、经营异常、被执行记录 `2.1` `5.3`
- [ ] 涉及需要资质的改动，公司有相应资质 `2.2`
- [ ] 没有在展厅当场交定金 `2.3`
- [ ] 看过至少一个正在施工的工地 `2.4`
- [ ] 合同写明了施工负责人和联系方式 `3.1`
- [ ] 问清了是否转包、分包，哪些项目由第三方做；合同写明禁止转包 `3.1` `5.7`
- [ ] 拿到了施工进度表，约定了验收通知方式 `3.2`
- [ ] 如请监理，确认了监理的独立性和服务范围 `3.3`

### 比报价

- [ ] 报价按最终确认的方案出，每项都有单位、数量、单价 `4.1`
- [ ] 按施工顺序核对过易漏项 `4.4`
- [ ] 材料写到品牌、型号、规格，写明了替代规则；主材在签约前已选定 `1.1` `4.2`
- [ ] 每项附了工艺做法，看过所有“另计”“按实际发生”的条件 `4.3` `4.4`
- [ ] 防水高度、找平厚度、墙面平整标准已写明 `4.3`
- [ ] 半包和全包按同一口径比较过 `4.5`

### 合同条款

- [ ] 签约前交的钱（定金、意向金、设计费）写明了性质、用途和退款条件 `1.4` `5.1`
- [ ] 每一期付款对应一个验收节点，尾款留到竣工验收之后 `5.2` `6.2`
- [ ] 问过能否资金存管、能否留质保金 `5.3`
- [ ] 增项和现场改动必须书面确认，计价方式已写明；增项款和其他款项都付给公司 `1.5` `3.1` `5.4`
- [ ] 结算超预算的上限和超出部分由谁承担已写明 `1.2` `4.4` `5.4`
- [ ] 工期起算、顺延条件、违约金已写明，双方对等 `5.6`
- [ ] 解约违约金和结算方式已写明 `5.7`
- [ ] 验收标准（国标、行标还是地方标准）已写明 `6.2`
- [ ] 空气检测的标准、委托方、不合格怎么处理已写明 `6.4`
- [ ] 防水、水电、基础装修、定制家具的保修期限和起算日已写明 `7.2`
- [ ] 报修后几天内上门、公司拒修怎么处理已写明 `7.3`
- [ ] 合同里没有“验收后不得再主张权利”这类条款 `5.8` `7.2`
- [ ] 所有承诺和优惠都写进合同并盖章 `5.8`
- [ ] 附件齐全（见下方“要拿到的材料”）`5.8`
- [ ] 如办装修贷，已问清放款对象和方式 `5.9`

### 全屋智能（选做）

- [ ] 布线、设备、调试、售后分别由谁负责已写明 `8.2`
- [ ] 签约主体有品牌授权 `8.2`
- [ ] 设备清单写到型号、数量和单价，安装调试费已写明 `8.5`
- [ ] 布线和点位在装修报价还是智能报价里，已说清 `8.3` `8.5`
- [ ] 场景清单和验收方式已写明 `8.5`
- [ ] 问清了断网和服务停止后哪些功能能用 `8.4`
- [ ] 摄像头位置和数据存储方式已确认 `8.6`

## 要拿到的材料

签字前逐份对照“里面要写明”，缺了哪项，让公司补进合同或附件再签。合同正文的几项是法规要求的必备内容，可以逐项勾选。

| 时间 | 材料 | 里面要写明 | 出处 |
| --- | --- | --- | --- |
| 签约时 | **合同正文，盖签约公司公章** | 双方名称、地址、电话；房屋间数和建筑面积；装修项目、做法、规格、质量要求和验收方式；开工和竣工日期；保修内容和期限；价格、计价方式、付款方式和时间；变更和解除的条件；违约责任和解决纠纷的途径；合同生效时间 | 5.8 |
| 签约时 | 分工清单（供应方／安装方／保修方） | 设计、主材、辅材、定制、家电、家具逐项写明谁供应、谁安装、谁保修 | 0.3、1.1 |
| 签约时 | 预算单，附工艺和用料说明 | 每项的名称、单位、数量、单价、工艺做法和用料；防水高度、找平厚度、墙面平整标准；每个“另计”“按实际发生”的条件；拆除、清运、搬运、管理费、税金是否另收 | 1.3、4.1、4.3、4.4 |
| 签约时 | 双方材料清单 | 每样材料的品牌、型号、规格、数量，由哪一方供应；缺货时怎么替换、替换要谁同意 | 1.1、4.2 |
| 签约时 | 赠送项目清单 | 每个赠送项目的名称、数量和型号 | 1.2 |
| 签约时 | 施工图纸 | 平面、顶面、立面、水电图各几张，交付日期；每页双方签字 | 1.4 |
| 签约时 | 材料供需时间表（半包） | 每样材料最晚到场日期；到场由谁验收；晚到或不合格时工期和费用怎么算 | 1.1、5.5 |
| 签约时 | 变更单、验收单、结算单、保修单的模板 | 变更单：变更内容、原价、新价、工期变化，双方签字；其他几张的内容见下面各行 | 5.4、5.8 |
| 签约时 | 智能设备清单、点位图、场景清单（选做） | 设备型号、数量、单价；安装调试费；布线和点位算在哪份报价里；每个场景怎么演示验收 | 8.3、8.5 |
| 开工前 | 物业装修管理服务协议；改结构或管道时的审批文件 | 施工内容和期限、允许施工的时间、垃圾清运方式、管理服务费、违约责任；押金和管理费由谁出 | 1.3、1.5 |
| 施工中 | 材料交接记录、各阶段验收单和结算单、变更单 | 交接记录：日期，材料品牌、型号、规格、数量，双方签字；验收单：验收项目和结果，双方（有监理时加监理）签字；结算单：这一期的金额 | 6.1、6.2、5.4 |
| 竣工时 | 遗留问题协议、空气检测报告（如约定） | 协议：每个遗留问题的处理方法、责任划分、完成期限、费用承担；检测报告：按约定的标准检测、由约定的一方委托 | 6.3、6.4 |
| 交接时 | 水电图和管线照片视频、收据或发票、保修单、代购产品的说明书和保修单 | 保修单：隐蔽工程（水电和防水）、其他基础装修、代购主材和定制家具家电分别写保修起止日期，双方签字盖章；收据或发票盖财务专用章 | 7.1、7.2 |
| 报修时 | 报修记录、问题照片和视频、付款凭证 | 报修日期和方式、问题描述、公司答复和上门日期 | 7.3 |
