## 2 筛公司

先筛掉明显有问题的，再比剩下几家的方案和报价。公司那边也有一套营销流程在筛客户（见 2.3）。[^1]

### 2.1 核对签约主体

**要点**：要查的是**签合同、收款的那家公司**，它和广告上的名字可能对不上。[^2]

**避坑**

- 宣传叫“某某装饰”，签约的可能是一家名字不同的科技公司，或者借用知名品牌标识的小公司。[^3]
- 签约的公司、收款的账户、实际施工的人，可能各是各的。[^4]

**要问**

- 合同上公司的全称和统一社会信用代码是什么？收款账户是不是这家公司的？
- 这家公司成立多久？有没有经营异常、被执行、失信记录？[^5]

### 2.2 资质和经营条件

**要点**：涉及结构、防水、燃气暖气改动的，必须委托有相应资质的企业。[^6]

**避坑**

- 看着像大品牌，甚至在大品牌门店里签约，签约方也未必是品牌方。[^3]
- 展厅大、样板间多说明不了实力，场地多是租的，展品多是供应商赞助的。[^7]

**要问**

- 物业申报需要资质证书复印件，公司能提供吗？[^6]
- 合同盖的章，和营业执照上的名字一致吗？[^8]

### 2.3 营销话术

**避坑**

- 低价全包、免费设计、限时特惠、“零增项”，是消协点名的引流方式。[^9]
- 带你看展厅、讲优惠活动、催你当场交定金，是事先设计好的一套流程。当场交钱可以拒绝。[^1]
- “顶级设计师”“国际认证”、刷出来的好评，要另找渠道核实。[^10]
- “我们的工人都是自己的”多半是营销说法。该问的是工人怎么结算、出了问题谁负责。[^11]
- 网上搜到的装修攻略很多是软文，包括带价格的“推荐”“排名”。[^12]

### 2.4 看工地和已交付案例

**要点**：样板间看不出施工水平，要看**正在施工**的工地，最好自己找，别只看公司安排的。[^13]

**避坑**

- 公司发来的工地照片和视频，代替不了自己去现场看。[^14]

**要问**

- 能不能去看一个正在做水电或瓦工的工地？能不能不提前通知？
- 能不能联系已经入住一两年的业主？

**看什么**：材料堆得整不整齐，现场干不干净，水电有没有拍照留底，工人干活认不认真。[^15]

## 3 谁来施工

合同签给装修公司，实际干活的是施工经理（工长）和他带的工人，工地做得好不好主要看施工经理。[^16]

### 3.1 施工负责人和分包

**要点**

- 合同里写明**施工负责人**的姓名和电话。[^17]
- 合同签给公司，工长的行为由公司负责。[^18]

**避坑**

- 不要把钱直接给工长或私下谈增项，出了问题公司可以不认。[^19]
- 前期报价压得低，工长接手后不是找你加钱，就是在材料和工艺上省。[^20]
- 公司可能把工程转包给没有资质的包工头。[^21]

**要问**

- 施工负责人是谁？中途能不能换？换人要不要经过我同意？
- 有没有转包、分包？哪些项目由其他人做（例如定制、门窗、燃气）？
- 增项单和收款，必须走公司吗？

### 3.2 进度和沟通

**要点**：要一份**施工进度表**，写明每个节点什么时候验收、你要什么时候到场。[^22]

**避坑**

- 一家公司同时接的工地太多，工期只能往后拖。[^23]
- 设计师、工长、工人之间的转达容易出错，特殊约定要自己盯。[^24]

**要问**

- 每个阶段谁通知我验收？提前几天通知？
- 有没有固定的沟通群和联系人？现场改动怎么确认？

### 3.3 要不要请第三方监理

**要点**：监理可以帮你审预算、陪签合同、做节点验收，不过各家水平差得很远。[^25]

**避坑**

- 公司自己配的质检或工程管家，主要为公司服务。[^26]
- 监理主动给你推荐装修公司的，要小心。[^25]

**要问**

- 监理是独立的第三方吗？和装修公司有没有关系？
- 包括哪些服务：审预算、陪签、几次验收？
- 监理合同由谁签、费用谁出、职责怎么写？[^27]

## 签约前核对清单（第 2、3 章）

- [ ] 核对了签约主体、收款账户、营业执照三者一致
- [ ] 查过签约公司的成立时间、经营异常、被执行记录
- [ ] 确认需要资质的改动，公司有相应资质
- [ ] 没有在展厅当场交定金
- [ ] 看过至少一个正在施工的工地
- [ ] 合同写明了施工负责人和联系方式
- [ ] 问清了是否转包、分包，哪些项目由第三方做
- [ ] 约定增项和付款都走公司
- [ ] 拿到了施工进度表和验收通知方式
- [ ] 如请监理，确认了监理的独立性和服务范围
