## 2. 结构对比后的取舍

- **网络长文**以“模式 → 坑 → 选公司”为主线，很少讲交付和售后，按全包、半包分开写“坑”的方式值得借鉴。
- **合同示范文本**覆盖了签约后的全过程，但没有“选模式、筛公司”的内容。
- **消协提示**补充了主体核验、定金与订金、资料留存、维权路径，这几点长文基本没写。
- **我们的取法**：按业主的决策时间线排列章节。模式选择放在最前；合同一章按示范文本的条款顺序组织；交付和售后单独成章。全包、半包的差异不拆成两份文档，而是在小节上标出来。

## 3. 大纲

每个小节都用固定模板：**要点 / 避坑 / 要问 / 要材料 / 不同说法 / 依据**。标签含义：`通用`、`全包`、`半包`。

### 0 先选模式

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 0.1 清包、半包、全包、整装各包什么 | 通用 | 示范文本列出的承包方式：包工不包料、包工部分包料、包工包料、按面积包干 |
| 0.2 自我评估：时间、是否懂行、预算、入住时间 | 通用 | 给判断维度，不给“哪种最好” |
| 0.3 混合方式与边界 | 通用 | 例如基础工程半包、定制和家电自购，边界必须写进合同 |

### 1 定范围：把“包什么”写成清单

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 1.1 主材和辅材分工清单 | **半包** | 每项写明谁供应、谁安装、谁保修（示范文本附件 2-2 的列） |
| 1.2 套餐包含与不包含 | **全包** | 户型限制、数量上限、可选范围、升级如何计价 |
| 1.3 拆除、清运、搬运、成品保护、物业费用 | 通用 | 容易漏掉的“其他费用” |
| 1.4 设计费与图纸范围 | 通用 | 免费到哪一步、哪些图纸要收费、设计变更 |
| 1.5 旧房、局部翻新和住着装修 | 通用 | 拆旧和基层修补的范围、物业申报手续、施工时间限制；能否住在里面施工 |

### 2 筛公司

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 2.1 主体核验 | 通用 | 签约、收款、施工主体是否一致；信用公示、执行信息查询 |
| 2.2 资质与经营条件 | 通用 | 按当地要求核对，不预设全国统一 |
| 2.3 识别营销话术 | 通用 | 低价全包、免费设计、限时特惠、样板间 |
| 2.4 看工地和已交付案例 | 通用 | 看什么、问谁，发布内容不等于现场核实 |

### 3 看交付：谁来干

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 3.1 施工负责人、班组、转包与分包 | 通用（全包重点） | 合同写明施工负责人；转包、分包如何约定 |
| 3.2 进度与沟通 | 通用 | 节点通知、进度记录、联系人 |
| 3.3 是否请第三方监理 | 通用 | 可选项，费用和职责另行约定 |

### 4 比报价

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 4.1 统一口径 | 通用 | 面积、工程量、计价单位，先统一再比总价 |
| 4.2 材料写到型号 | 通用 | 品牌、系列、型号、规格、数量 |
| 4.3 工艺做法表 | 通用 | 例如防水高度、找平厚度，写明“另计”的条件 |
| 4.4 易漏项与“按实际发生” | **全包**为主 | 模糊表述、“另计”、恶意漏项 |
| 4.5 半包与全包报价怎么换算比较 | 半包＋全包 | 把自购主材补进来，再按同口径比较 |

### 5 核合同

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 5.1 定金、订金与首付款 | 通用 | 两者性质不同；退款条件写清楚 |
| 5.2 付款节点挂钩验收、质保金 | 通用 | 按节点付款，比例看当地示范文本，不给统一数字 |
| 5.3 预付款风险与资金存管 | 通用 | 公司收款后跑路的风险；是否支持第三方存管，存管机构和划款条件是什么 |
| 5.4 变更与增项流程 | 通用 | 先书面确认再施工；变更怎么计价 |
| 5.5 自购材料的交接与责任 | **半包** | 共同验收交接；材料不合格或延误时由谁负责、工期是否顺延 |
| 5.6 工期起算、顺延与逾期违约金 | 通用 | 哪些原因可以顺延，是否对等 |
| 5.7 解约、结算与转包违约 | 通用 | 开工前和施工中解约分别怎么处理 |
| 5.8 口头承诺、签章主体与附件 | 通用 | 口头承诺写入合同，附件齐全，签章主体与营业执照一致 |
| 5.9 公司推荐的装修分期或贷款 | 通用 | 贷款发放给谁、额度是否超过工程款、放款是否与施工进度挂钩；公司停工后贷款怎么办 |

### 6 施工中的节点

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 6.1 材料进场验收 | 通用（半包重点） | 双方都在场，对照清单 |
| 6.2 分阶段验收 | 通用 | 隐蔽工程、木瓦、油漆、竣工；不合格不进入下一阶段。具体工艺链接知识库各施工阶段 |
| 6.3 遗留问题怎么处理 | 通用 | 写明问题、处理方法、期限、费用 |
| 6.4 室内空气检测 | 通用 | 是否纳入竣工验收；参照哪个标准、由谁委托检测机构、不合格怎么处理（示范文本写的是“可参照”GB 50325） |

### 7 交接与售后

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 7.1 交接资料 | 通用 | 水电图、隐蔽工程照片、发票或收据、保修单、材料凭证 |
| 7.2 保修期限与范围 | 通用（半包重点） | 不同项目分别保修多久；自购材料由谁保修。可以引用全国性规定《住宅室内装饰装修管理办法》第三十二条的最低保修期限（引用前核对原文） |
| 7.3 报修与纠纷处理 | 通用 | 报修响应；先协商，再找 12345 或消协，最后仲裁或诉讼；全程保留资料 |

### 8 全屋智能（选做）

2026-11-17 新增。资料见 [第 8 章资料整理](guide-refs-ch8-20261117.md)。

| 小节 | 标签 | 内容 |
| --- | --- | --- |
| 8.1 做多少 | 通用 | 高频功能少；先留线，设备按需添置 |
| 8.2 谁来做 | 通用 | 装修公司打包、品牌服务商、自己买；布线、设备、调试、售后分别由谁负责 |
| 8.3 水电阶段要预留什么 | 通用 | 零线、加深底盒、网线、网关位置、各类电源 |
| 8.4 选生态 | 通用 | 兼容、本地联动、服务停止的风险、互联互通标准 |
| 8.5 报价、合同和验收 | 通用 | 设备清单、安装调试费、场景验收、售后时限 |
| 8.6 隐私 | 通用 | 摄像头位置、数据存储、敏感个人信息 |

## 5. 采集顺序

按章节逐步补齐，每完成一章就复核一次缺口：

1. **第 0、1 章（模式与范围）**：半包分工和全包套餐的边界是全文的基础。
2. **第 4 章（比报价）**：现有卡相对多，可以最先出样稿。
3. **第 5 章（核合同）**：以官方示范文本为主，视频补经验。
4. **第 3、7 章（交付与售后）**：团队、分包、半包保修。
5. **第 2、6 章**：以官方资料和现有卡为主，视频少量补充。

## 6. 不写的内容

- 每平米单价、市场均价、“合理利润”。
- 统一的付款比例和质保金比例。示范文本中的数字只作为“某地区建议值”展示，并写明出处。保修期限只引用全国性规定中的最低期限。
- 推荐具体的资金存管机构或贷款产品。
- 推荐或排名任何公司，包括参考文章里推荐的公司。
- 法律效力判断。只写“合同里应约定什么”，不写“这样约定一定有效”。
