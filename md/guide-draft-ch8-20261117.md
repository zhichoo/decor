## 8 全屋智能（选做）

全屋智能和装修关系最大的是**墙里的线**：设备可以入住后再买，线一旦封进墙就很难改。[^1]

### 8.1 做多少

**要点**

- 天天用的通常只有几样：进门开灯、离家断电、窗帘、门锁、传感器。[^2]
- 先把墙里的线留足，设备按需要慢慢添。[^1]

**避坑**

- 智能家居投诉最多的，是宣传的功能和实际用起来差得远。[^3]
- 场景配得越复杂，越需要有人长期维护；家里没人会调，系统很容易瘫掉。[^4]

### 8.2 谁来做

常见三种做法：装修公司打包、品牌服务商单独做、自己买设备自己装。选哪种都要先分清**布线谁做、设备谁供、调试谁做、出问题找谁**。

**避坑**

- 售后通常是“谁卖给你找谁”，品牌总部往往不管代理商。[^5]
- 智能设备商和装修电工分属两家时，接错线容易互相推诿。[^5]
- 跨品牌设备的联动，服务商可能不做深度打通。[^6]

**要问**

- 布线、设备、安装调试、售后，分别由谁负责？
- 签约主体有没有品牌授权？
- 布线图由谁出，电工是否签字确认？

### 8.3 水电阶段要预留什么

**要点**：这一步要在**水电交底前**告诉设计师和电工，封墙后再补就要开槽。[^7]

| 位置 | 预留 |
| --- | --- |
| 所有开关底盒 | 零线；用加深底盒 [^8] |
| 每个房间 | 网线，规格写到超六类 [^9][^10] |
| 弱电箱 | 电源插座 [^11] |
| 网关 | 房子中部，常电插座，不放进金属弱电箱 [^7] |
| 窗帘盒 | 顶部电源 |
| 入户门 | 门锁旁插座；门外摄像头留网线和电源位置 [^12] |
| 扫地机器人、智能马桶、投影、电动晾衣架 | 常电插座 |
| 人体传感器、中央空调检修口 | 供电 |

**避坑**

- 没留零线只能用单火开关，带小功率 LED 灯可能频闪、关灯微亮。[^8]
- 签约时就说清楚要做智能，让对方把零线和额外点位算进报价。只得到一句口头的“够用”，开工后可能变成点位超标要加钱。[^13]

### 8.4 选生态

**避坑**

- 不同品牌之间仍有兼容问题，可能要装多个 App。[^3]
- 厂商可能通过升级改变功能，服务停止后部分功能可能无法使用。[^14]
- 断网后能不能本地联动，要提前确认。[^14]
- 互联互通方面，国家已有推荐性标准，强制性标准还在制定中。写着“支持某协议”，也不代表所有功能都能互通。[^15]

**要问**

- 断网后哪些功能还能用？
- 服务停止后，设备还能怎么用？
- 现有家电（空调、冰箱、洗衣机）能接进来吗？能做到哪一步？
- 换路由器后要不要重新配置？谁来配？[^16]

### 8.5 报价、合同和验收

**避坑**

- 同样的户型和需求，两份智能报价可能差一倍；要拆开看设备、辅材施工、调试售后三部分。[^17]
- 报价写着某品牌生态，实际可能是贴牌的第三方设备。[^17]
- 安装费、辅材打包成一口价，就看不出哪里贵。[^17]

**要问**

- 设备清单是否写到型号、数量和单价？
- 套餐价含不含安装、调试？超出部分怎么计价？
- 布线和点位是在装修报价里，还是在智能报价里？[^18]
- 交付哪些场景？验收时能否逐条演示？
- 售后响应时限和保修期是多久？

**要材料**：带型号和单价的设备清单，点位图，场景清单，验收记录。

### 8.6 隐私

**避坑**

- 门锁的指纹、人脸，家用摄像头影像，多属于敏感个人信息。[^19]

**要问**

- 摄像头装在哪些位置？卧室装不装？
- 数据存在哪里？能不能只存本地？
- 账号能否注销，授权能否撤回？

## 签约前核对清单（第 8 章）

- [ ] 布线、设备、调试、售后的责任方已写明
- [ ] 签约主体有品牌授权
- [ ] 水电交底前已给出智能布线清单
- [ ] 所有开关底盒留零线
- [ ] 网关位置和电源已确定
- [ ] 设备清单写到型号和单价
- [ ] 安装调试费已写明
- [ ] 场景清单和验收方式已写明
- [ ] 问清了断网和服务停止后能用哪些功能
- [ ] 摄像头位置和数据存储方式已确认

## 注释

[^1]: 用户经验汇总（什么值得买，2026-08-25）：按寿命把投入分三层，墙里的布线最难改，协议和网关几年后可能迭代，设备可以入住后再加。

[^2]: 《法治日报》2026-11-04 调查：多名受访者表示，真正用到的高频功能只有几项，例如进门开灯、离家断电、洗衣结束提醒。用户经验汇总把门锁、灯光、窗帘、传感器列为高频四件套。

[^3]: 《法治日报》2026-11-04 引用市场监管总局数据：2025 年全国 12315 平台收到智能设备投诉举报 15.2 万件，其中智能家居 2.9 万件，集中在过度宣传、升级失败、App 闪退、兼容性差。江苏省消保委调查：受访者中近六成遇到过问题，品牌间不兼容，手机“变成 App 收纳盒”。

[^4]: 《法治日报》2026-11-04：一位程序员受访者说，普通家庭中负责调试的人一旦顾不上，整套系统容易陷入瘫痪；一位从业者说，场景越复杂，调试成本和售后风险越高，有服务商因此交付低配版本。

[^5]: 用户经验汇总（什么值得买，2026-08-11）：从业者称“目前智能家居行业就是谁卖你的，找谁售后”；有用户遇到代理商售后推诿，品牌总部不管。另一个案例中，电工接错线烧坏开关和屏幕，引出“该找谁”的争议。建议开工前写清楚由谁出布线图、谁的电工接线、谁做通电测试。

[^6]: 《法治日报》2026-11-04：一位智能家居工作室经营者说，每打通一个第三方设备，服务商就要多承担一层售后风险，很多服务商索性不做深度打通。

[^7]: 用户经验汇总（什么值得买，2026-08-25）列出的布线清单，包括网关放在房子几何中心、留常电插座、不要塞进金属弱电箱，以及窗帘盒、扫地机器人、智能马桶、投影、晾衣架、传感器、空调检修口的供电预留。

[^8]: 同上：智能开关需要零线供电；只能用单火开关时，配小功率 LED 灯可能频闪、关灯微亮；智能开关模块较厚，建议用加深底盒。

[^9]: 知识库：每个房间留一根网线，后期装有线 mesh `claim_9f5c5833`；可以不布光纤，但不要只布光纤不布网线 `claim_0ee48e26`。

[^10]: 知识库：网线必须用超六类，五类已经被淘汰 `claim_9b07ee56`。

[^11]: 知识库：弱电箱留一个排插，给路由器、光猫供电 `claim_7de181d2`。

[^12]: 知识库：入户门处装插座，方便给智能锁充电 `claim_e868d6e5`；门口留网线装有线监控 `claim_774434f3`；门外单独走电线和网线 `claim_045915bf`；案例：门外只留了电源线，摄像头适配器没地方装 `claim_6476100e`。

[^13]: 法治日报-家装乱象（2025-11）：天津一位业主的合同没写水电点位数量，设计师当初说“每个房间至少两个点位”，地暖回填后公司按“超一个点位加 300 元”要求补交 1.495 万元。什么值得买（2026-11-14）：建议签约前问清点位预留和网络改造由谁负责、怎么收费。

[^14]: 用户经验汇总（什么值得买，2026-08-25）：有用户反映厂商通过 OTA 升级改变了已有功能；建议确认联动能否本地执行、不依赖云端。《法治日报》2026-11-04 律师建议关注“相关服务停止后哪些功能仍可正常使用”。

[^15]: GB/T 46456.1-2025《信息技术设备互连 智能家居互联互通 第 1 部分：架构与通用要求》，2026-02-01 实施，是推荐性标准。商务部等 8 部门《促进智能家居消费行动方案》（2026-09-02）提出“加快制定实施智能家居互联互通等强制性国家标准”。用户经验汇总认为 Matter 协议目前多打通开关、亮度、温度等基础操作。

[^16]: 《法治日报》2026-11-04：一位受访者换了路由器后，所有联动失效，花了几天重新配置。

[^17]: 什么值得买 2026-11-14 汇总小红书晒单：同户型、需求相近的两份全屋智能报价，一份 8000 元、一份 16000 元；常见的膨胀点是“生态标”贴牌第三方硬件、灯带和走线按米报价时单价被抬高、安装费打包成一口价。文中数字为个案。

[^18]: 《法治日报》2024-06-04 增项调查：一位业主做了全屋智能，合同写 56 个水电点位，实际做了 125 个，超出部分另收费（见第 1 章注释 19）。

[^19]: 《法治日报》2026-11-04 律师意见：智能门锁采集的指纹、人脸信息，以及能识别特定个人的家用摄像头影像，多属于个人信息保护法所列的敏感个人信息，企业处理时应取得个人单独同意。
