## 4 比报价

几家报价的项目和数量对齐了，总价才有可比性。[^1]

### 4.1 对齐项目和数量

**要点**

- 报价单通常按房间排列，看着项目很全，却很难对比。按施工顺序逐项对照，更容易发现漏了什么（见 4.4）。[^2]
- 每一项都要看清**单位、数量、单价**。只写总价、不写数量的项，后面最容易加钱。

**避坑**

- 签约前就要拿到按**最终确认方案**出的详细清单。先让你签字、说详细清单“明天再送”的，后面容易加项。[^3]
- 面积、米数、点位数可以自己量、自己数。有业主自己量过，美缝米数最后减了一半。[^4]
- 消协调查里最常见的报价问题，是项目拆得过细、重复收费。[^5]
- 报价单上的面积、数量要按实测；“面积算少了”是开工后补款最常见的理由之一。[^6]
- 报价明显比其他几家低的，差价往往会在增项里补回来。[^7]

**要问**

- 这份报价是按哪一稿方案做的？
- 每一项的数量是怎么算出来的？实际施工时多出来的部分怎么计价？
- 有没有只写总价、没写数量的项目？

### 4.2 材料写到型号

**要点**：只写品牌不够，要写到**品牌、系列、型号、规格、数量**。同一个品牌，不同系列价格可能差好几倍。[^8]

**避坑**

- 先签合同、后选主材，签完常会发现看得上的款式都要加钱。主材要在签约前选到型号。[^9]
- 约定的品牌可能被换掉，要写明可以接受哪些替代品。[^10]
- 材料到场时对照清单验收，型号不对当场拒收。[^11]

**要问**

- 每种材料是否写到型号和规格？
- 缺货时用什么替代？由谁确认？
- 套餐里的标配款是哪几款？能否先看实物？

### 4.3 工艺做法

**要点**：每个项目都应附**工艺做法和用料说明**，并写明哪些情况会“另计”。[^12]

**避坑**

- 做法说明里常有“超过某厚度另报”“斜铺另计”“拉缝加收”这类条件，签约前要逐条看。[^13]
- 瓷砖铺贴价通常按某个规格起步，大砖、小砖、上墙都可能加钱。[^14]
- 防水高度、找平厚度、墙面找平标准不写清楚，施工方容易按最低标准做。[^15]

**要问**

- 每一项写了哪些“另计”条件？
- 防水刷多高？找平按多厚报价？墙面做到什么平整标准？
- 瓷砖铺贴价按什么规格起步？我选的规格要不要加钱？

### 4.4 易漏项和“按实际发生”

**要点**：下面这些项目最常被漏报或低报，对着自己的报价逐项找。[^2]

| 阶段 | 常见漏项 |
| --- | --- |
| 拆旧 | 垃圾外运、短驳费、上楼费、电梯保护；旧地面和墙砖拆除后的修补；老房墙面铲到红砖重新粉刷 |
| 土建 | 地面找平超厚；新砌墙的植筋、挂网、双面粉刷；卫生间地梁、挡水坎、门头过梁 |
| 水电 | 入户线、强电箱；点位数量；开槽补槽和暗盒是否另算；线径；面板及安装；零线；水管米数；下水改造；地暖和中央空调配套 |
| 瓦工 | 瓷砖规格起步价；粘接剂；倒角、对缝；窗台石、过门石；美缝；包管、壁龛 |
| 木工 | 吊顶数量和造型；窗帘盒；空调风口；灯具开孔 |
| 油漆 | 墙面找平标准；网格布；调色数量 |
| 杂费 | 管理费、税金、设计费、保洁费 |

**避坑**

- 合同写了“一价全包”或者“加价不超过 5%”，开工后照样可能不断增项。签约前把漏项补进清单，才真正管用。[^16]
- “按实际发生结算”要配一个上限，并写明增项必须先书面确认才能施工（见第 5 章）。[^17]

**要问**

- 上表各项是否都在报价里？不在的，是不需要做，还是没算进去？
- 结算能超出预算多少？超出部分谁承担？

### 4.5 半包和全包怎么比

**要点**

- 半包报价不含主材，比较时要把自己买主材的钱加上，再和全包比。
- 全包要看套餐标配的是什么，再把你实际想要的升级项加上。[^9]
- 先定方案，再对项目、选材料，最后签合同。[^9]

**避坑**

- 全包套餐里没逐项写明的五金、灯带等，收尾时可能被说成“不在全包范围”。[^18]

**要问**

- 半包：我要买的主材清单有哪些？施工方负责哪些辅材？
- 全包：哪些是标配，哪些要加钱？我选的款式算标配还是升级？

## 签约前核对清单（第 4 章）

- [ ] 报价按最终确认的方案出
- [ ] 每一项都有单位、数量、单价
- [ ] 按施工顺序核对了易漏项
- [ ] 材料写到型号和规格，写明了替代规则
- [ ] 主材在签约前已选定
- [ ] 每一项附了工艺做法，看过所有“另计”条件
- [ ] 防水高度、找平厚度、墙面平整标准已写明
- [ ] 结算超预算的上限和承担方已写明
- [ ] 半包和全包按同一口径比较过

## 注释

[^1]: 上海一位装修从业者（V2EX 转贴，2026-05）：“全包”“半包”没有严格界定，报价不含某项照样可以叫全包，“不看项目只看总价，没任何意义”。

[^2]: 同上。作者建议按施工顺序（拆旧、土建、水电、瓦工、木工、油漆、安装、杂费）核对报价，并逐阶段列出了常见的漏报和低报项目，上表据此整理。

[^3]: 法治日报-家装乱象（2025-11）：天津一位业主付了 60% 首付款后才收到详细清单，设计师签约时说“清单没问题，详细版明天送过来”；记者调查发现，有的公司签约时只给框架清单，付款后才提供详细清单，其中暗藏“预收费用超支补款”等条款。

[^4]: 同一帖评论区，另一位业主：美缝报了 500 多米，自己量下来不到一半，最后减了一半；工长说点位不够，业主到现场数了开好的洞，实际比套餐还少十几个。

[^5]: 山东省消协 2025 年家装家居消费调查（14186 份问卷）：60.49% 的受访者遇到过项目拆分过细、重复收费，32.49% 遇到过虚报工程量，33.17% 遇到过把损耗费、税费、运费藏在报价单里。

[^6]: 法治日报-家装乱象（2025-11）：上海一位业主开工一个多月后，项目经理以“吊顶面积计算少了”要求补款 8522 元。人民日报（新华网 2025-08-29）：重庆一位业主遇到“报价时漏算防水面积，后期按实际面积补收高价费用”，公司以合同写了“按实际发生计算”为由。

[^7]: 上海一位装修从业者（V2EX 转贴，2026-05）：同城、同标准的报价，差三五千可以理解，差一万以上就要警惕；“装修没有上限，但是有下限，低于这个下限，一切承诺都不成立。”这是从业者的个人观点。

[^8]: 湖南日报 2025-07 报道引装修业内人士：“同一品牌、同类产品分不同等级，价格和品质也有差别”；报道中一位业主的全包套餐“材料虽为品牌，却很低端，选购高端品牌要加钱”。

[^9]: 上海一位装修从业者（V2EX 转贴，2026-05）称之为“假施工合同”：先按套餐标配材料签施工合同，签完去选主材，看中的都要加钱升级。建议主材在签约前选到型号，顺序是“定方案，对项目，选材料，签合同”。

[^10]: 人民日报（新华网 2025-08-29）引西南大学副教授刘培森：合同中标注“某品牌或同等档次产品”，后期公司可能以缺货为由推荐高价替代品。

[^11]: 京津冀示范文本第 7.2 条：材料到场时，双方就品牌、型号、规格、数量、质量、环保等共同验收。第 9.11 条：乙方实际使用的材料品牌、型号、规格、数量与合同不符的，甲方有权要求赔偿。

[^12]: 京津冀示范文本第 1.5 条：“工程预算单应当与材料质量工艺标准配套编制”；附件一《工程预算单》每项都有“工艺做法、用料说明”一栏。

[^13]: 黑龙江示范文本附件 3《工程内容和做法一览表》中的写法，例如：瓷砖铺贴“水泥砂浆厚度 2cm 以内，如超过此厚度需另报墙面找平项目”“斜铺拼花费用另计”“拉缝粘贴每米加收”；墙面基层处理“棚面空鼓龟裂费用另计”。

[^14]: 上海一位装修从业者（V2EX 转贴，2026-05）：瓦工报价一般按 800×800 等规格起步，大砖、小规格砖、墙砖薄贴都可能加人工和材料费。

[^15]: 上海一位装修从业者（V2EX 转贴，2026-05）：防水涂刷高度、地面找平厚度、墙面找平标准（顺平、垂平、冲筋）都会影响价格，要在报价阶段确认。

[^16]: 新民网 2026-10：38㎡ 老房“一价全包”7 万元，开工后先以“不含拆旧”加 1 万，后又列出数十项增项要加 6.3 万余元，两次合计超过合同总价，业主拒付后公司停工，最终解约。法治日报-家装乱象（2025-11）：上海一位业主的合同写明不改设计时总价增减不超过预算的 5%，施工中仍以吊顶面积算少、墙面基层未算、吊柜要加宽为由三次增项共 2.8 万余元，远超 5% 的上限（9040 元）；业主不同意就停工，最后付了 2.18 万元。

[^17]: 京津冀示范文本第 1.5 条：没有变更时按实际发生量结算，增幅不超过预算的 5%；第 9.6 条：未经甲方书面同意，乙方随意增项，费用由乙方承担。

[^18]: 法治日报-家装乱象（2025-11）：广州一位业主已付到总价的 90%，收尾时设计师在群里通知“五金件、屋内灯带均不在全包范围内”，要补交 3.2 万元，否则停工。
