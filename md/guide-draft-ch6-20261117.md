# 指南样稿：第 6 章 施工中的节点

日期：2026-11-17。格式与前几章相同。资料见 [第 0、1 章引用稿](guide-refs-ch0-1-20261116.md)、[经验分享](guide-refs-experience-20261117.md)，本章新增来源列在文末“本章新增来源”。

各阶段具体查什么（打压、闭水、空鼓、平整度等）不在本章重写，链接到知识库对应施工阶段的验收卡片。本章只写**程序**：谁到场、什么时候签字、不合格怎么办。

## 6 施工和验收

每个阶段验收合格、你签了字，再进入下一阶段、付下一笔钱。[^1]

### 6.1 材料进场验收　`半包重点`

**要点**：材料到场前要通知对方，双方在现场对照清单核对品牌、型号、规格、数量，并签交接记录。[^2]

**避坑**

- 你买的材料，施工方说不合格，你又书面同意继续用的，出了问题由你承担。[^3]
- 公司供的材料与约定不符，你有权禁止使用、要求更换。[^4]
- 合同写“某品牌或同等档次”的，后期可能以缺货为由换成别的产品，进场时要逐项核对。[^5]

**要问**

- 每批材料谁通知我、提前几天？我不在时谁代签？
- 公司供的材料有没有合格证和检测报告？[^6]

**要材料**：材料交接或验收记录（品牌、型号、数量、签字）。

### 6.2 分阶段验收

**要点**：一般分四次验收：**水电（隐蔽工程）、木瓦、油漆、竣工**。每次签验收单，付款节点跟着验收走。[^7]

每个阶段你自己也能查几项：

| 阶段 | 自己可以查 |
| --- | --- |
| 水电 | 拿图纸逐个对开关、插座和水路点位；水管做打压测试 [^8] |
| 防水 | 闭水试验放满水 48 小时，请物业到楼下看顶棚 [^9] |
| 瓦工 | 用空鼓锤敲砖，重点敲墙砖四角和窗洞四周 [^10] |
| 油漆 | 用 2 米靠尺查墙面平整度，用激光水平仪查阴阳角 [^11] |

**避坑**

- 公司通知了验收，你在约定时间内既不去也不提异议，可能被视为验收合格。[^12]
- 没通知你就进入下一阶段的，你可以要求停工，损失由公司承担。[^12]
- 前一道工序没验收，下一道的工人不要进场。[^13]
- 水电完工后，你到现场签字确认了，再封槽、贴砖。[^14]
- 钱付早了，后面就管不住。有业主材料一进场就付清全款，之后工期一拖再拖，官司打赢了钱也难要回。[^15]
- 施工全程拍照录像，在微信群里沟通留痕；封槽前把管线走向拍下来，以后报修用得上。[^16]

**要问**

- 按哪个验收标准（国标、行标还是地方标准）？[^17]
- 每次验收谁到场：工长、公司质检、我请的监理？
- 打压、闭水试验能不能等我到场再做？

**要材料**：每个阶段的验收单和对应的结算单，双方签字。[^18]

### 6.3 遗留问题

**要点**：竣工时还有小问题，可以先签**遗留问题协议**再入住，写明问题、处理方法、责任、期限、费用。[^19]

**避坑**

- 没验收就搬进去住，法院可能视为工程已交付，你还得付清剩余款项。[^20]
- 对方说问题“在允许误差范围内”不肯重做的，可以找市场监管部门调解。有业主定制家具验收时发现缝隙、尺寸偏差，调解后餐边柜重做。[^21]
- 对质量有争议、协商不成的，可以委托第三方检测，不合格的由公司承担检测和返工费用。[^22]

**要问**

- 遗留问题多久处理完？逾期不处理，能不能从尾款或质保金里扣？

### 6.4 室内空气检测

**要点**：合同里写明四件事：**是否纳入竣工验收、参照什么标准、谁委托检测机构、不合格怎么办**。[^23]

**避坑**

- 一方单独委托的检测，对方可能不认，最好在公司人员在场时委托第三方检测。[^24]
- 公司治理后不及时复测，打官司时房租损失可能只被支持一部分。[^25]
- 合同写明空气质量要达标、写了违约责任的，法院支持赔偿，有判决返还部分装修款的。[^26]
- 返还装修款不一定包括主材款。[^24]

**要问**

- 竣工验收包不包括空气检测？检测费谁出？
- 不合格后多少天内治理完？违约金怎么算？治理后仍不达标怎么办？

## 核对清单（第 6 章）

- [ ] 每批材料到场都有交接记录，品牌型号与合同一致
- [ ] 每个阶段验收后签了验收单，再付对应款项
- [ ] 打压、闭水等测试自己在场或有监理在场
- [ ] 封槽、贴砖前拍了管线照片和视频
- [ ] 尾款留到竣工验收之后
- [ ] 竣工遗留问题写进了协议，有期限
- [ ] 空气检测的标准、委托方、不合格处理已写进合同
- [ ] 竣工验收前没有提前入住
